Personal notes and hands-on exercises from Anthropic Academy's **Claude with Amazon Bedrock** course.

The course covers how to build applications with Claude on Amazon Bedrock: calling the API
(`InvokeModel` and `Converse`), prompt evaluation and prompt engineering, tool use, retrieval
augmented generation (RAG), Claude features such as extended thinking, vision, citations and
prompt caching, the Model Context Protocol (MCP), and agents with Claude Code and Computer Use.
